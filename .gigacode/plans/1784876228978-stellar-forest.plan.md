# План работы: Переключатель HTML-PDF в настройках облачного хранилища

## 📋 Общее описание

В окне "Настройки облачных хранилищ" добавлен переключатель "HTML - PDF". При включенном переключателе в положении PDF отчет сначала генерируется в HTML формате, затем конвертируется в PDF с сохранением дизайна. HTML файл сохраняется в отдельной папке "Отчеты в HTML" на телефоне, а отправляется только PDF файл.

---

## 📁 Существующие компоненты

### Ключевые файлы:

1. **CloudSettingsScreen.kt** - экран настроек с переключателем `Opochki` (true=HTML, false=PDF)
2. **HtmlToPdfConverter.kt** - класс для конвертации HTML в PDF
3. **CloudStorageManager.kt** - генерация HTML отчетов и загрузка в облако
4. **EmailManager.kt** - отправка email с вложениями
5. **SharedPrefsManager.kt** - хранение настроек

### Текущий поток работы (HTML режим):

```
CloudSettingsScreen (Opochki = true)
    ↓
SharedPrefsManager.sendReportWithLink()
    ↓
CloudStorageManager.generateHtmlReport()
    ↓
CloudStorageManager.uploadHtmlToDiskDirect() или EmailManager.sendEmailWithAttachment()
```

---

## 🎯 Изменения в логике (PDF режим)

### При `Opochki = false`:

```
1. Генерируем HTML отчет
   ↓
2. Сохраняем HTML файл в папку "Отчеты в HTML"
   ↓
3. Конвертируем HTML в PDF (HtmlToPdfConverter.convertHtmlToPdf())
   ↓
4. Отправляем только PDF файл
```
