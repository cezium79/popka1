# План исправления бага индекса чекпоинта

## Цель
Исправить ошибку "Точка вне очереди" при нажатии "Назад" в экране фотографирования чекпоинта.

## Текущее состояние
- Индекс чекпоинта увеличивается через `updateCurrentCheckpointIndex()`
- Есть метод `rollbackCheckpointIndex()` для отката индекса на 1
- Флаг `isPhotoCheckpointPassed` используется для предотвращения двойного увеличения индекса

## Требования
1. Увеличивать индекс необходимо ТОЛЬКО в одном месте: когда показывается диалоговое окно о прохождении чекпоинта (CheckpointPassed dialog)
2. Во всех остальных местах необходимо убрать команду на увеличение индекса
3. При нажатии "Назад" в окне фотографирования индекс должен оставаться без изменений
4. Индекс должен увеличиваться только при показе диалога "Точка зафиксирована"

## Текущие изменения
### Измененные файлы:
- `SharedPrefsManager.kt` - Добавлен метод `rollbackCheckpointIndex()`
- `PhotoCaptureScreen.kt` - Убран вызов `onCheckpointComplete()`, добавлен прямой вызов `updateCurrentCheckpointIndex()` в LaunchedEffect(showCheckpointPassedDialog) (пока закомментирован)
- `MainActivity.kt` - Закомментирован `onCheckpointComplete` в конфигурации photo_capture экрана
- `OhrannikCabinetScreen.kt` - Добавлен флаг `isPhotoCheckpointPassed`, добавлена проверка в LaunchedEffect(showCheckpointPassedDialog) для условного увеличения индекса

## Ключевые исправления
1. **PhotoCaptureScreen.kt** - Убраны вызовы `rollbackCheckpointIndex()` из обработчиков кнопки "Назад" (TopAppBar и BackHandler). Индекс теперь **остается без изменений** при нажатии "Назад", что позволяет повторно сканировать тот же QR-код.

2. **OhrannikCabinetScreen.kt** - Исправлен порядок действий в `LaunchedEffect(showCheckpointPassedDialog)`. Сначала проверяется `if (!isPhotoCheckpointPassed)` и увеличивается индекс, **только потом** флаг сбрасывается в `false`.

3. **OhrannikCabinetScreen.kt** - Исправлена опечатка `activeRoundIndexQ` → `activeRoundIndex` в диалоге вопросов.

4. **Флаг `isPhotoCheckpointPassed`** - Используется для предотвращения двойного увеличения индекса. Устанавливается в `true` при переходе на экран фото, сбрасывается в `false` после показа диалога и увеличения индекса.

## Критерии успеха
- Индекс увеличивается только один раз при прохождении фото-чекпоинта (в PhotoCaptureScreen)
- Индекс увеличивается только один раз при прохождении QR/NFC-чекпоинта (в OhrannikCabinetScreen с проверкой `!isPhotoCheckpointPassed`)

- Ошибка "Точка вне очереди" не появляется при корректном прохождении чекпоинтов
