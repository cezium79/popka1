# План: Исправление рендеринга таблицы чекпоинтов в PDF

## Проблема

Таблица чекпоинтов в PDF остаётся пустой. Причина: хрупкий формат сериализации. Данные таблицы сериализуются в строки вида `|||CHECKPOINT_ROW|||checkpoint|time|guard|status|action|`, потом десериализуются split по `|`. Двойные разделители `|||` создают пустые элементы, индексы сдвигаются — данные не попадают в таблицу.

## Решение

Убрать сериализацию таблицы в строки. Передавать `List<ShiftLogEntry>` напрямую в функцию отрисовки. Строки таблицы из `buildReportContent` убрать, оставить только текстовые строки контента.

**Логика парсинга:**
- Найти строки `|||LOGS_FOR_ROUND|||<roundId>`
- Для каждого roundId собрать `CheckpointRow` из `ShiftLogEntry` через фильтр: `allLogs.filter { it.roundId == roundId }.sortedBy { it.timestamp }`
- Конвертировать `ShiftLogEntry` → `CheckpointRow`:

```kotlin
fun ShiftLogEntry.toCheckpointRow(): CheckpointRow = CheckpointRow(
    checkpointName = checkpointName,
    timestamp = timestamp,
    employeeName = employeeName,
    isAborted = hasAborted,
    actionText = buildActionText(),
    hasViolation = !isSequenceCorrect
)

private fun ShiftLogEntry.buildActionText(): String = when (actionType) {
    "QUESTION" -> "${questionText ?: "Вопрос"}: ${answer ?: "-"}"
    "INPUT" -> "${inputTitle ?: "Ввод"}: ${inputValue ?: "-"}"
    "PHOTO" -> "Фото: снято"
    else -> "Проход"
}
```

**Если есть нарушения — добавлять ` ⚠` к actionText.**
