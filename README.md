# Ohrana — Система контроля обходов охранников

Android-приложение для мониторинга и контроля обходов объектов охраны.

## 📋 Возможности

- **Управление сменами** — начало/закрытие смен с фиксацией времени
- **Маршруты обходов** — настройка маршрутов с чекпоинтами
- **NFC/QR сканирование** — контроль прохождения точек через NFC или QR-коды
- **Вопросы и ответы** — интерактивные опросы в процессе обхода
- **Фотофиксация** — снятие фотографий с привязкой к чекпоинтам и координатам
- **Нарушения последовательности** — контроль порядка прохождения точек
- **Происшествия** — фиксация инцидентов с фото и геолокацией
- **События работников** — учёт приходов/уходов персонала объекта
- **Отчёты** — генерация HTML-отчётов со статистикой и логами
- **Отправка по email** — автоматическая отправка отчётов через SMTP
- **Облачное хранение** — загрузка отчётов в Яндекс.Диск и Yandex Cloud
- **Файловое хранение смен** — каждая смена сохраняется как JSON-файл

## 🏗 Архитектура

### Хранение данных

- **SharedPreferences** — настройки, чекпоинты, маршруты, будильники
- **JSON-файлы** — данные закрытых смен (папка `/Download/Ohrana/Shifts/`)

## 🔧 Настройка

### Требования

- **minSdk**: 30 (Android 11)
- **targetSdk**: 34 (Android 14)
- Kotlin 1.9+
- Android Gradle Plugin 8+

### Конфигурация

1. Клонировать репозиторий
2. Открыть проект в Android Studio
3. Синхронизировать Gradle-зависимости
4. Настроить SMTP/облачные сервисы в UI

### Cloud Storage

Приложение поддерживает загрузку отчётов в:
- **Yandex Cloud Storage** — через REST API (PUT-запросы)
- **Yandex Disk** — через Yandex API v1 (OAuth 2.0)

**Описание**

Ohrana — это мобильное приложение для Android, предназначенное для контроля обходов охранников на объектах. Приложение позволяет:

- Настраивать маршруты обходов с чекпоинтами
- Фиксировать прохождение точек через NFC или QR-коды
- Вести журнал событий и протоколов нарушений
- Формировать детализированные отчёты по каждой смене
- Отправлять отчёты по email и в облачное хранилище

### Ключевые особенности

- ✅ Поддержка NFC и QR-сканирования
- ✅ Гибкая настройка маршрутов и чекпоинтов
- ✅ Контроль последовательности прохождения точек
- ✅ Фотофиксация с координатами
- ✅ Автоматическая генерация отчётов (HTML)
- ✅ SMTP-отправка по расписанию
- ✅ Хранение данных в JSON-файлах
